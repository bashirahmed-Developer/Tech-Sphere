> An ultra-modern, responsive consumer electronics & tech gadgets online store featuring category filtering, slide-over cart drawer, instant coupon codes, and seamless **Cash on Delivery (COD)** checkout flow.

---

## ✨ Key Features

- **⚡ Flagship Electronics Catalog**: Laptops (MacBook M3, ASUS ROG), Smartphones (iPhone 16 Pro, S24 Ultra), Audio (Sony XM5, AirPods Pro), Gaming Gear (PS5 Pro, Mechanical Keyboards), Smartwatches, and Drones.
- **💵 100% Cash On Delivery (COD) Checkout**:
  - Zero card details required.
  - Form validation with customer phone, full address, city selection, and order notes.
  - Realistic order confirmation screen with unique Order ID (#TS-XXXXX) and verification notice.
- **🛒 Interactive Slide-Over Cart Drawer**:
  - Live item count with badge bounce animation.
  - Quantity increment (+) / decrement (-) controls and 1-click trash removal.
  - Free delivery progress indicator.
  - Working Coupon Codes (e.g. `TECH10` for 10% OFF, `WELCOME20` for 20% OFF).
  - Persistent state saved in `localStorage` (no data loss on refresh).
- **🔍 Multi-Category Filtering & Real-Time Search**: Instant live search by product name, brand (Apple, Sony, Samsung), and specs.
- **🔍 Product Quick View Modal**: High-res product showcase with full technical specifications (RAM, Processor, Battery, Display, Warranty).
- **❤️ Wishlist System**: Save favorite tech gadgets with 1-click "Move to Cart".
- **🌓 Neo-Cyberpunk Dark & Clean Light Modes**: Fluid theme engine with persistent memory.
- **🎉 Animated Confetti**: Celebratory order confirmation particle effects.
