TechSphere is a high-performance, portfolio-grade e-commerce web application dedicated exclusively to flagship consumer electronics, laptops, smartphones, gaming consoles, studio audio, and aerial optics.

Built with an ultra-modern neo-cyberpunk aesthetic, glassmorphic UI, real-time filtering, interactive product showcases, and a streamlined **100% Cash on Delivery (COD)** checkout experience tailored for nationwide delivery across Pakistan.

## 🌟 Key Features

### 1. 3D Interactive Hero Showcase
- Rotating flagship devices (Apple MacBook Pro M3 Max, ASUS ROG Zephyrus OLED, iPhone 16 Pro Max, Sony WH-1000XM5) with live specs pills and one-click cart addition.
- Dynamic flash sales countdown timer with live seconds ticker.
- Real-time customer trust metrics (50K+ delivered, ₨ 0 advance required).

### 2. Comprehensive Hardware Catalog (17 Flagships)
- **Laptops & PCs:** MacBook Pro M3 Max, ASUS ROG Zephyrus G16 OLED, Dell XPS 15 OLED, Lenovo Legion Pro 7i.
- **Smartphones:** iPhone 16 Pro Max (PTA Approved), Samsung Galaxy S24 Ultra, Google Pixel 9 Pro XL.
- **Audio & Acoustics:** Sony WH-1000XM5, AirPods Max USB-C, Bose QuietComfort Ultra.
- **Wearables:** Apple Watch Ultra 2, Galaxy Watch 6 Classic.
- **Gaming & Consoles:** PlayStation 5 Pro 2TB, Steam Deck OLED 1TB, Logitech G Pro X Superlight 2.
- **Drones & Optics:** DJI Mini 4 Pro Fly More Combo, Sony Alpha A7 IV.

### 3. Smart Filtering & Instant Search
- Instant category pills with real-time product counts.
- Dynamic price range slider with live formatted PKR ceiling.
- Multi-criteria sorting: Featured, Price Low-to-High, Price High-to-Low, Highest Rated, and Highest Discount.
- Synchronized navbar search and catalog search with instant `x` clear button.

### 4. Interactive Cart Drawer & Promo Engine
- Slide-over glassmorphic drawer with item thumbnails, quantity steppers, and remove controls.
- Active coupon validation engine:
  - `TECH10` - 10% discount
  - `WELCOME20` - 20% discount
  - `COD5` - 5% discount
  - `VIP15` - 15% discount
- Live free express shipping progress meter.

### 5. Streamlined Cash on Delivery (COD) Checkout
- Strictly Cash on Delivery — zero credit/debit card friction.
- Form inputs for Name, Phone/WhatsApp, City selector, and Street Address.
- Celebratory canvas confetti animation upon order confirmation.
- Randomized unique tracking order ID (`#TS-XXXXX`).
- Formatted printable / downloadable order receipt.

## 🛠️ Architecture & Tech Stack

- **Markup:** Semantic HTML5 with accessibility attributes and ARIA roles.
- **Styling:** Vanilla CSS3 featuring custom properties, CSS Grid, Flexbox, glassmorphism backdrop-filters, and responsive media queries.
- **Logic:** Vanilla JavaScript (ES6+) with state management, LocalStorage caching, and asynchronous DOM manipulation.
- **Icons & Visuals:** Font Awesome 6.5, Google Fonts (*Space Grotesk* & *Plus Jakarta Sans*), Unsplash CDN.

## 💻 Local Setup & Execution

```bash
# 1. Clone the repository
git clone https://github.com/bashirahmed-Developer/Tech-Sphere.git

# 2. Navigate to project directory
cd Tech-Sphere

# 3. Start local development server (Node.js)
node server.js

# 4. Open in browser
# http://localhost:3001/
```
